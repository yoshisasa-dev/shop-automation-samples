# 見本5：LINE×AI 自動応答（ヘアサロン ことり・架空のお店）

お客さんが LINE で質問すると、お店の「よくある質問」シートをもとに Claude（AI）が答えます。
わからない質問・割引や体のことなど答えない方がよい質問は、AI は答えずに「スタッフからご連絡します」と返し、お店にメールで知らせます。

- 置き場所：Google スプレッドシート＋そのシートに付いた Google Apps Script（GAS）
- LINE の受け口：GAS のウェブアプリ（`https://script.google.com/macros/s/<デプロイID>/exec`）
- AI：Claude（モデルは「設定」シートの「AIモデル」で指定。初期値 `claude-haiku-5-5`）

## シート
| シート | 中身 |
|---|---|
| 設定 | 店名・通知先メール・営業時間・定休日・予約ページURL・使いすぎ防止の上限 |
| よくある質問 | カテゴリ・質問・答え・公開（チェックを外すとAIは使わない）。AIの答えの根拠はここだけ |
| 会話ログ | 日時・お客さん（LINEの表示名）・質問・答え・引きつぎ・理由 |
| お試し | 「お試しで質問する」の結果（LINEなしで確かめられる） |
| ログ | エラーなどの記録 |

## 設置の手順
### 0. コードを入れる
1. お店用の Google アカウントで、新しいスプレッドシートを作る
2. 「拡張機能」→「Apps Script」を開く
3. `src/` の `.gs` ファイル（Api・Common・Line・Logic・Sample・Setup）を、同じ名前のスクリプトファイルとして作って中身を貼る
4. エディタの「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、`src/appsscript.json` の中身で置きかえて保存する
   - [clasp](https://github.com/google/clasp) を使う場合は、`.clasp.json` の `rootDir` を `src` にして push しても同じです

### 1. 初期設定
1. スプレッドシートを開き直す（メニュー「💬 サンプル店」が出ます）
   - Google アカウントを複数使っている場合は、Chrome のシークレットウィンドウなどで設置用アカウントだけでログインしておくと、権限の確認でつまずきにくくなります
2. メニュー「💬 サンプル店」→「初期設定（最初に1回）」→ 権限の確認で「許可」
3. 「サンプルの「よくある質問」を入れる」（自分のお店の内容に書きかえて使います）
4. 「設定」シートで、店名・通知先メール・営業時間・定休日・予約ページURL などを入れる

### 2. Claude のキーを入れて、お試しする（LINEなしで動く）
1. Claude の開発者ページ（Console）で APIキーを作る
2. メニュー「🔑 キーを設定」→ 1つ目の入力欄に APIキーを貼る（2つ目の LINE は、まだなら空のままOK）
3. メニュー「お試しで質問する」→「駐車場はありますか？」「安くなりませんか？」などを入れて、答えを確かめる

### 3. LINE とつなぐ
1. LINE公式アカウントを作る（LINE Official Account Manager。無料プラン）
2. 「設定」→「Messaging API」→「Messaging APIを利用する」で LINE Developers のチャネルを作る
3. LINE Developers のチャネル →「Messaging API設定」→「チャネルアクセストークン（長期）」を発行してコピー
4. スプレッドシートの「🔑 キーを設定」→ 2つ目の入力欄に貼る（1つ目は空のままでOK）
5. スクリプトエディタ（「拡張機能」→「Apps Script」）の「デプロイ」→「デプロイを管理」で、ウェブアプリのURL（`/exec` で終わるもの）をコピーする
   - まだデプロイしていなければ、「新しいデプロイ」→ 種類「ウェブアプリ」、実行するユーザー「自分」、アクセスできるユーザー「全員」で作る
6. メニュー「LINEに貼るWebhook URLを表示」→ 小窓に 5 のURLを貼る → 出てきたURL（最後に `?k=…` がつく）を、LINE Developers の「Webhook URL」に貼って保存 →「Webhookの利用」をオンにする
   - `/dev` で終わるテスト用のURLは LINE から使えないので、貼っても「URLの形がちがいます」と出て止まります
   - 2回目からは、URLが同じなら小窓は空のまま「OK」でかまいません
7. LINE Official Account Manager の「応答設定」で、「応答メッセージ」をオフ、「Webhook」をオンにする
   - LINE Developers の「Webhookの再送」は**オフのまま**にする（GAS の仕組み上、オンにすると同じメッセージが2回届くため。2回目は自動で無視しますが、オフが安全です）
8. スマホの LINE で、作った公式アカウントを友だち追加して、質問を送る

※ LINE Developers の「検証」ボタンはエラー（302）と出ることがありますが、GAS の仕組み上のもので、実際のメッセージは届きます。

## 安全のための工夫
- **秘密の文字列つきのURL**：GAS では LINE の署名（本物の LINE から来たかの印）を確かめられないため、Webhook URL に長い秘密の文字列を付け、合わないものは無視します。このURLは人に教えないでください
- **キーはシートに書かない**：APIキーと LINE のトークンは、スクリプトの中だけに保存します（画面には最後の4文字だけ表示）
- **使いすぎ防止**：同じ人は10分に5通まで・1日20回まで、AI を使うのはお店全体で1日200回まで（設定で変えられます）。こえたらスタッフに引きつぎます。お店への引きつぎメールは、同じ人について1時間に1通まで
- **数式にしない**：お客さんのメッセージや名前が「=」で始まっても、会話ログには文字として残します（シートの数式として動かないように）
- **1対1のトークだけ**：グループやトークルームに招待されても答えません
- **再送・重複は無視**：同じメッセージが2回届いても、1回だけ答えます
- **思わぬエラーでも返事をする**：処理の途中で失敗しても、お客さんには「スタッフからご連絡します」と返します
- **AI が失敗しても無視しない**：AI のエラー・キーの未設定・返事が読めないときは、必ず「スタッフからご連絡します」と返してお店に知らせます
- **答えの根拠を限る**：AI には「よくある質問」以外のことを答えないよう指示し、割引・医療・予約の空き・クレームは引きつぎにします

## 気をつけること
- スプレッドシートの**編集権限がある人は、キーを見たり変えたりできます**（スクリプトの設定から見えるため）。スタッフに「よくある質問」を直してもらうときは、シートの保護などで範囲を分けるか、信頼できる人だけに編集権限を渡してください
- AI は「よくある質問」以外を答えないよう指示していますが、言い回し次第で思わぬ返事をする可能性はゼロではありません。会話ログをときどき確かめてください
- お店全体の1日の上限に達したあとは、多くの人について引きつぎメールが届くことがあります（無料のGoogleアカウントは1日100通ほどが上限）
