# 設置手順書：ケーキ予約のネットショップ（パティスリー こむぎ・サンプル店）

この見本を、自分の Shopify ストアに入れて動かすまでの手順です。
練習するときは、無料で作れる **開発用ストア（Dev store）** を使うのがおすすめです（本物の決済は発生しません）。

所要時間：40分くらい

流れ：Horizon を入れる → `custom/` のファイルを足す → 差し込みをする → テーマエディタで設定する → `setup_store.py` で商品などを作る → 確認メールを直す → 動作を確かめる

## 0. 準備するもの
- Shopify のストア（開発用ストアで OK）。以下では `your-store.myshopify.com` と書きます
- [Shopify CLI](https://shopify.dev/docs/api/shopify-cli)（`shopify store execute` が使える新しいバージョン。`shopify version` で確認）
- Python 3
- Google Chrome（商品のイラスト画像を作るときだけ使います。スクリプトは Mac の Chrome の場所を前提にしています）

ターミナルで、このフォルダ（`samples/04-shopify-cake`）に移動しておきます。

## 1. テーマストアから Horizon を入れる
このリポジトリには、テーマ本体（Horizon）は入っていません。Shopify のテーマストアから入れます。

1. 管理画面の「オンラインストア」→「テーマ」を開く
2. 「テーマライブラリー」に Horizon がなければ、「無料テーマを探す」から **Horizon** を選んで追加する
3. 追加した Horizon の「︙」→「コードを編集」を開く

この見本は Horizon v4.3.0 で作りました。新しいバージョンでは、差し込む場所の前後が少し変わっていることがあります。

## 2. custom/ のファイルを足す
「コードを編集」の画面で、`snippets` フォルダの「新しいスニペットを追加」を押し、名前を `pickup-datetime` にして作ります。
中身を `custom/snippets/pickup-datetime.liquid` の内容に置きかえて保存します。

> Shopify CLI に慣れている場合は、`shopify theme pull` でテーマを手元に取り、`custom/snippets/pickup-datetime.liquid` を `snippets/` に置いてから `shopify theme push` で戻しても同じです。

## 3. Horizon に差し込みをする
くわしい場所は [README.md](README.md) の「Horizon に加えた変更」にあります。

1. **カートに入力欄を出す**：`snippets/cart-summary.liquid` を開き、`<div class="cart__ctas">`（チェックアウトボタンを囲むところ）のすぐ上に、次の1行を足して保存する

   ```liquid
   {% render 'pickup-datetime', section_id: section_id %}
   ```

2. **テーマ設定に「受け取り日時」を足す**：`config/settings_schema.json` を開き、いちばん最後の `]` の手前（最後のグループの `}` のうしろ）にカンマを打ってから、`custom/config/settings_schema-pickup.json` の中身を貼って保存する

保存でエラーが出なければ OK です。テーマエディタの「テーマ設定」に「受け取り日時」が出ます。

## 4. テーマエディタで設定する
「オンラインストア」→「テーマ」→ Horizon の「カスタマイズ」を開き、[README.md](README.md) の「3. テーマエディタで設定した内容」の表のとおりに設定します。

- トップページ：「カスタムLiquid」セクションを2つ足し、`custom/theme-editor/intro.liquid` と `custom/theme-editor/order-steps.liquid` の中身を貼る
- ヘッダーの告知バー・フッターの文言を変える
- 商品テンプレート `cake` を作り、「特記事項」ブロックを2つ（メッセージプレート・ろうそく）足す
- 「テーマ設定」→「カート」で「簡単なチェックアウトボタン」をオフにする
- 「テーマ設定」→「受け取り日時」で、お店に合わせて定休日や受け取り時間を変える（最初の値のままでも動きます）

ヒーローの画像と、特集コレクションで選ぶ「ケーキ」「焼き菓子」は、まだストアにありません。手順5のあとで選びます。

## 5. setup_store.py で商品などを作る
`setup_store.py` が、Shopify CLI の `store execute`（Admin GraphQL）で中身を作ります。
同じハンドルのものがすでにあれば作り直さないので、`products`・`archive`・`site` は何回実行しても大丈夫です。

1. 商品のイラスト画像を作る（商品写真の代わりに使います）

   ```bash
   python3 images/make.py        # ケーキ・焼き菓子 7枚 → images/out/
   python3 images/make_hero.py   # トップページの看板画像 → images/out/hero.png
   ```

   `images/out/` に PNG ができれば OK です（このフォルダはリポジトリには入れていません）。

2. CLI がストアを操作できるよう、許可をとる（ブラウザが開きます）

   ```bash
   shopify store auth --store your-store.myshopify.com \
     --scopes write_products,write_files,write_online_store_pages,write_online_store_navigation,write_locations,write_shipping
   ```

3. 対象のストアを環境変数 `SHOPIFY_STORE` に入れて、実行する

   ```bash
   export SHOPIFY_STORE=your-store.myshopify.com
   python3 setup_store.py all    # 商品 → テスト商品のアーカイブ → コレクション・ページ・メニュー・店頭受け取り
   python3 setup_store.py hero   # トップページの看板画像を「ファイル」に上げる（1回だけ）
   ```

   引数ごとの動きは次のとおりです。`python3 setup_store.py` だけで実行すると、この使い方が出て終わります。

   | 引数 | すること |
   |---|---|
   | `products` | 商品7点を作る（ケーキ4点はサイズ 4号・5号・6号で値段が変わり、テンプレート `cake` を使う） |
   | `archive` | 最初から入っているテスト商品をアーカイブする（消しません） |
   | `site` | コレクション（ケーキ・焼き菓子）・ご利用ガイド・店舗のご案内・メニュー・店頭受け取りを作る |
   | `hero` | 看板画像 `hero.png` を「コンテンツ」→「ファイル」に上げる。実行するたびに1枚増えるので1回だけ |
   | `all` | `products` → `archive` → `site` を順に実行（`hero` は入りません） |

   - 店頭受け取りの場所は、架空の住所で登録されます。実際のお店で使うときは、管理画面の「設定」→「ロケーション」で直してください

4. テーマエディタに戻り、手順4で残したところを選ぶ
   - トップページの「ヒーロー」：画像に `hero.png`
   - 1つ目の「特集コレクション」：コレクション「ケーキ」
   - 2つ目の「特集コレクション」：コレクション「焼き菓子」

   選び終わったら、テーマを「公開する」にします（まだ公開していない場合）。

## 6. 注文確認メールに受け取り日時を出す
1. 管理画面の「設定」→「通知」→「注文の確認」→「コードを編集」を開く
2. `<p>{{ email_body }}</p>` のすぐ下に、`notifications/order-confirmation-pickup.liquid` の中身（コメントの下の部分）を貼る
3. 保存する

メッセージプレート・ろうそくの入力は、もとのテンプレートが商品の明細の中にそのまま表示します。

## 7. 動作を確認する
1. ストアを開き、ケーキの商品ページでサイズを変えると値段が変わることを確かめる
2. メッセージプレート・ろうそくを入れてカートに入れる
3. カートで、受け取り日と受け取り時間を選ぶ
   - 3日後より前の日や、定休日（火曜日）は選べないことを確かめる
4. 開発用ストアなら、Shopify の「テスト用の支払い（Bogus Gateway）」で試し注文をする
5. 管理画面の注文の画面に「受け取り日」「受け取り時間」とプレートの文字が出ること、確認メールに受け取り日時が出ることを確かめる
