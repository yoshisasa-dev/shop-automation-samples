# 設置手順書：注文受付の自動化（まるっと弁当・サンプル店）

所要時間：15分くらい

## 0. 準備
- **試すためのGoogleアカウント（無料のGmailアカウントでOK）でログインします。**
  普段のアカウントと混ざらないよう、Chromeの「プロフィール」を分けるか、シークレットウィンドウを使うのがおすすめです。
- 画面の右上のアイコンが、使いたいアカウントになっていることを確認してから進めてください。

## 1. スプレッドシートを作る
1. ブラウザで `sheets.new` を開くと、新しいスプレッドシートができます
2. 名前はあとで自動で「まるっと弁当（サンプル店） 注文管理」に変わるので、そのままでOK

## 2. コードを貼る
1. スプシのメニュー「拡張機能」→「Apps Script」を開く
2. 左の「ファイル」の横の「＋」→「スクリプト」で、次の6つを作る（名前の「.gs」は自動で付きます）
   - `Logic` / `Common` / `Order` / `Setup` / `Daily` / `Sample`
3. それぞれに、`src` フォルダの同じ名前のファイルの中身をまるごと貼る
4. 最初からある「コード.gs」は、右の「︙」→「削除」で消す
5. 左の歯車「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
6. エディタに出てきた `appsscript.json` の中身を、`src/appsscript.json` の中身に貼り替える（タイムゾーンが東京になります）
7. 上の💾ボタンで保存

> clasp に慣れている場合は、`src` フォルダをそのまま `clasp push` しても大丈夫です（使うアカウントで `clasp login` してください）。
> `clasp create --parentId <スプレッドシートID> --rootDir src` は `src/appsscript.json` を上書きしてタイムゾーンが New York になるので、push の前に `Asia/Tokyo` に戻してください。

## 3. 初期設定
1. スプシのタブに戻って、ページを再読み込みする
2. メニューに「🍱 サンプル店」が出るので、「初期設定（最初に1回）」を押す
3. 「承認が必要です」と出たら：
   - 「続行」→ 使っているアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」
     （自分のアカウントに貼ったスクリプトなので大丈夫です）
   - 「許可」を押す
4. 承認のあと、もう一度「初期設定（最初に1回）」を押す
5. 「初期設定が終わりました 🎉」とフォームのURLが出れば完了です

## 4. 動作を確認する
1. 「🍱 サンプル店」→「フォームのURLを表示」で出たURLを開き、試しに注文する
   - 受け取り日は **明後日以降の日曜以外** にすると「受付済み」になります
2. 「注文一覧」シートに1行増えていればOK
3. 設置したアカウントのGmailに2通届いていればOK
   - 【デモ】ご注文を承りました（お客さん宛てのメール。デモモードなのでお店に届きます）
   - 【新着注文・受付済み】（お店宛ての通知）
4. わざと「今日」や「日曜日」を受け取り日にして注文すると、「受付不可」になってピンク色の行になります

## 5. 見本のデータを入れる
1. 「🍱 サンプル店」→「サンプル注文を入れる」
   - 架空のお客さんの注文が26件入ります（うち2件は締め切り後で受付不可）
   - メールは送られません
2. 「🍱 サンプル店」→「明日の製造数を今すぐ集計」
   - 「製造数」シートに商品別・時間別・アレルギー一覧ができて、Gmailに製造数のメールが届きます
3. 最初の状態に戻したいときは「注文一覧をリセット」→「サンプル注文を入れる」で、毎回同じ見本に戻せます

## 知っておくと安心なこと
- **デモモード（設定シート）**：「OFF」と書かない限り、フォームに知らない人のメールアドレスが入力されても、メールはお店（設置したアカウント）にしか届きません。試しているあいだはONのままにしてください
- **いたずら対策**：フォームに入力された文字は、スプシの式として動かないように記録します。1回の注文は30個まで、受け取り日は30日先までに制限しています（設定シートで変えられます）
- **メールの上限**：無料のGoogleアカウントは、1日に送れるメールが100通くらいまでです。残りが10通を切ったら、お客さん宛ては送らずにお店宛て（新着・製造数）を優先します
- **毎日の集計メール**：毎日16時に、翌日分の注文があれば製造数のメールが届きます。止めたいときは、Apps Scriptの左の時計マーク「トリガー」から `dailyProduction` を削除してください
- **設定を変えたら**：受け取り時間・受け取り方法・メニューを変えたら「フォームの商品・選択肢を更新」、集計時刻を変えたら「初期設定」をもう一度押してください
- **通知先メール**：設定シートの「通知先メール」が空なら、設置したアカウントに届きます。別のアドレスに届けたいときは、ここに書いてください
