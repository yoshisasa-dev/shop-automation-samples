# 設置手順書：勤怠管理（カフェ ひだまり・サンプル店）

所要時間：20分くらい

## 0. 準備
- Googleアカウントを1つ用意してログインします（試すときは、普段使いと別のアカウントがおすすめです）
- 普段のアカウントと混ざらないよう、Chromeのシークレットウィンドウを使うと安心です
- パソコンに [clasp](https://github.com/google/clasp)（Apps Script をコマンドで扱う道具）を入れ、`clasp login` でログインしておきます

## 1. スプレッドシートを作って、コードを送る（clasp）
clasp でスプレッドシートごと作ります（すでにあるスプレッドシートに `--parentId` で付けようとすると「Requested entity was not found」になることがあります）。
```bash
cd samples/02-attendance
clasp create --type sheets --title "カフェ ひだまり（サンプル店） 勤怠管理" --rootDir src
```
- `clasp create` は `src/appsscript.json` を上書きしてタイムゾーンが New York になり、Webアプリの設定も消えます。**push の前に、次の内容に戻してください**
```json
{"timeZone":"Asia/Tokyo","dependencies":{},"exceptionLogging":"STACKDRIVER","runtimeVersion":"V8","webapp":{"executeAs":"USER_DEPLOYING","access":"MYSELF"}}
```
```bash
clasp push --force
```
- 表示された「Created new document」のURLが、勤怠管理のスプレッドシートです

## 2. 初期設定
1. スプレッドシートを再読み込みすると、メニューに「⏰ サンプル店」が出ます
2. 「初期設定（最初に1回）」を押す
3. 「認証が必要です」と出たら、承認します（承認の窓が開かないときは、Chromeのシークレットウィンドウで開き直してください）
   - 使うアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「すべて選択」にチェック →「続行」
4. もう一度「初期設定（最初に1回）」を押し、「初期設定が終わりました 🎉」が出れば完了です

## 3. 打刻画面を公開する
```bash
clasp deploy --description "打刻画面"
```
- 表示された デプロイID を使って `https://script.google.com/macros/s/<デプロイID>/exec` を開くと、打刻画面が出ます
- 見本では **自分だけが開ける** 設定（`access: MYSELF`）です。知らない人が打刻できないようにするためです
- 実際のお店で使うときは `access` を `ANYONE_ANONYMOUS`（だれでも開ける）にして、暗証番号で守ります

## 4. 見本のデータを入れる
1. 「⏰ サンプル店」→「サンプルの打刻を入れる」
   - 架空のスタッフ6人の、過去5週間の打刻が入ります（毎回同じ内容）
   - 打刻忘れが2件まざります。今日の分は、今の時刻までの打刻だけ入ります（「勤務中」の人が出ます）
2. 「打刻忘れを今すぐチェック」を押すと、打刻の確認メールが届きます
   - 届け先は「設定」シートの「通知先メール」です。空なら設置したアカウントに届きます

## 5. 動きを確かめる画面
| No | 画面 | 見どころ |
|---|---|---|
| 1 | 打刻画面（スマホ表示） | 名前ボタンと暗証番号の入力 |
| 2 | 打刻画面・ボタン | 暗証番号を入れたあと。出勤中の人を選ぶと「休憩」「退勤」だけ押せる |
| 3 | 月の集計 | スタッフ別の時間とお給料の目安 |
| 4 | 勤怠（日別） | 打刻忘れのピンクの行と、勤務中の黄色い行 |
| 5 | 打刻の確認メール | 打刻忘れの日とスタッフの一覧 |
| 6 | 設定シート・スタッフシート | 締め日や時給をシートで変えられる |

## 知っておくと安心なこと
- **時刻**：打刻の時刻は、スマホの時計ではなくGoogle側の時計で記録します
- **暗証番号**：5回まちがえると、その人は10分間打刻できなくなります
- **打刻の修正**：「打刻ログ」シートの日時を書きかえて、「今月の集計を作る」を押します。書きかえた記録は「ログ」シートに残ります
- **端数処理**：最初は1分単位です。15分単位などの切り捨ては法律上問題になることがあるので、変えるときはお店で確認してください
- **お給料の目安**：時給×時間に、残業・深夜の割増を足した目安です。交通費や控除は入っていません
- **毎朝のチェック**：毎日9時に過去7日の打刻忘れを調べ、あればメールします。止めたいときは、Apps Scriptの「トリガー」から `dailyCheck` を削除してください
- **実際のお店で「全員」に公開するとき**
  - 見本の暗証番号（1234 など）は必ず変える。「スタッフ」シートは店長以外に共有しない（暗証番号が見えるため）
  - 打刻画面のURLを知っている人は、名前の一覧（スタッフIDと名前）を見られます
  - 暗証番号を5回まちがえると10分間ロックし、お店にメールで知らせます。いたずらで特定の人をロックされることはありえるので、続くときは打刻画面を公開し直して（URLを変えて）ください
  - メニューの操作（初期設定・集計・リセットなど）は、打刻画面からは呼べないようにしてあります（管理者のアカウントで開いたときだけ動く）
- **打刻忘れのメール**：毎朝のチェックでは、前に知らせた打刻忘れはもう一度は送りません。メニューの「打刻忘れを今すぐチェック」は、見つかった分をすべて送ります
