# 設置手順書：予約管理（整体サロン ゆるり・架空のサンプル店）

所要時間：20分くらい

## 0. 準備
- Googleアカウントを1つ用意します（見本を試すだけなら、ふだん使っていないアカウントがおすすめです）
- パソコンに Node.js と [clasp](https://github.com/google/clasp)（Apps Script をパソコンから送る道具）を入れておきます
  ```bash
  npm install -g @google/clasp
  clasp login
  ```
- Apps Script の API を有効にしておきます（https://script.google.com/home/usersettings で「オン」）
- 承認の画面は、ふつうのブラウザ（Chrome など）で開いてください。アプリの中のブラウザでは、承認の窓が開けないことがあります

## 1. スプレッドシートを作って、コードを送る（clasp）
```bash
cd samples/03-reservation
clasp create --type sheets --title "整体サロン ゆるり（サンプル店） 予約管理" --rootDir src
```
- `clasp create` は `src/appsscript.json` を上書きします。**push の前に、次の内容に戻してください**
```json
{"timeZone":"Asia/Tokyo","dependencies":{},"exceptionLogging":"STACKDRIVER","runtimeVersion":"V8","webapp":{"executeAs":"USER_DEPLOYING","access":"MYSELF"}}
```
```bash
clasp push --force
clasp deploy --description "予約画面"
```
- `clasp create` でできる `.clasp.json` には、あなたのスクリプトIDが入ります。公開リポジトリには入れないでください

## 2. 初期設定
1. スプレッドシートを開くと、メニューに「📅 サンプル店」が出ます
2. 「初期設定（最初に1回）」を押す
3. 「認証が必要です」と出たら、承認します
   - 設置したアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「すべて選択」にチェック →「続行」
   - **Googleカレンダー** の許可も求められます（予約用のカレンダーを作るため）
4. もう一度「初期設定（最初に1回）」を押し、「初期設定が終わりました 🎉」が出れば完了です
   - Googleカレンダーに「整体サロン ゆるり（サンプル店） 予約」というカレンダーができます

## 3. 予約画面を公開する
- 「📅 サンプル店」→「予約画面のURLを表示」で出るURLを開くと、予約画面が出ます
- 見本の設定は **自分だけが開ける**（`access: MYSELF`）です
- お店で使うときは、`src/appsscript.json` の `access` を `ANYONE_ANONYMOUS`（だれでも開ける）にして、もう一度 `clasp push --force` と `clasp deploy` をします。そのURLをホームページやSNSに貼ります

## 4. 見本のデータを入れる
1. 「📅 サンプル店」→「サンプル予約を入れる」
   - これから2週間の架空の予約が入ります（毎回同じ内容。1件はキャンセル済み）
   - 2日後に「私用（歯医者）」の予定も入ります。その時間は予約画面に出ません
2. 「明日のリマインドを今すぐ送る」を押すと、明日の予約のお知らせメールが届きます（デモモードなので、お客さま宛てのメールもお店の通知先に届きます）

## 5. 本番で使うとき
- 「設定」シートの「店名」「通知先メール」「営業時間」「定休日」などを、お店に合わせて書きかえます
- 「メニュー」シートで、メニュー名・時間・料金を書きかえます。行を足せばメニューが増えます
- 「デモモード」を `OFF` にすると、お客さま宛てのメールがお客さまに届くようになります
- 「リマインドの時刻」を変えたら、「初期設定（最初に1回）」をもう一度押してください（何度押しても、入力済みの設定や予約は消えません）

## 知っておくと安心なこと
- **ダブルブッキング**：予約の直前に、もう一度カレンダーの空きを確かめます。同時に2人が同じ時間を押しても、あとの人には「たった今うまりました」と出ます
- **私用の予定**：予約用カレンダーに予定を入れると、その時間は予約画面に出なくなります（終日の予定ならその日はまるごと）
- **いたずら対策**：同じメールアドレスで入れられる、これからの予約は3件まで（設定で変えられます）
- **キャンセル**：確認メールのリンクから。締め切り（最初は前日18時）を過ぎると、画面に「お電話で」と出ます
- **リマインド**：毎日18時に、翌日の予約のお客さまへ送ります。1つの予約に1回だけです
- **メニューの操作**：初期設定・リマインド・サンプル・リセットは、管理者のアカウントで開いたときだけ動きます（予約画面からは呼べません）
- **リセット**：「予約をリセット」は、予約一覧と、このシステムが入れたカレンダーの予定（予約・サンプル）だけを消します。店長が自分で入れた予定は消しません

## 気をつけること
- **Googleカレンダーの1日の回数制限**：無料アカウントでは、カレンダーの予定を1日にたくさん作ったり消したりすると「1日にサービス calendar を実行した回数が多すぎます」と止まります。「サンプル予約を入れる」は1回で約40件の予定を作り・消すので、**1日1〜2回まで**にしてください。止まったら、翌日にもう一度「サンプル予約を入れる」を押せば元に戻ります
  - ふつうのお店の使い方（1日に数件〜数十件の予約）なら、この制限にはかかりません
- **メールの1日の送信数**：無料アカウントでは、1日に送れるメールの数に上限があります。残りが少なくなると、お店宛ての通知を優先し、お客さま宛ては送らずに「ログ」シートに記録します
